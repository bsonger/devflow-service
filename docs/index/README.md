# Index

## 这个文档解决什么问题

`docs/index/` 只负责导航。
如果你还不知道该看哪一层文档，先看这里。

它不解决实现细节问题，也不定义当前事实。

## 当前入口文件

- `getting-started.md`：新人和首次进入仓库的最短阅读路径
- `agent-path.md`：Agent 视角的紧凑导航图
- `agent-recipes.md`：常见任务的快速跳转
- canonical agent start: [AGENTS.md](../../AGENTS.md)

## 使用规则

- 找文档，从这里开始
- 判断“现在代码到底怎么工作”，去 `docs/system/`
- 判断“哪个服务拥有哪个资源”，去 `docs/services/`
- 判断“接口和字段长什么样”，去 `docs/resources/` 或 `docs/api/`

## Notes

- 不要把 `docs/index/` 当事实层
- 不要在这里复制一套架构或 API 说明
