# Guides

## 这个文档解决什么问题

`docs/guides/` 放的是“怎么做”的文档。

它适合回答：

- 本地怎么开发
- 怎么新增模块、service、handler、API
- 怎么更新 OpenAPI
- 改完之后怎么验证

## 当前文档

- `local-development.md`
- `backend-change-playbook.md`
- `openapi-workflow.md`

## 与其他目录的边界

- 看当前事实：去 `docs/system/`
- 看资源定义：去 `docs/resources/`
- 看 API 契约：去 `docs/api/`
- 看长期硬规则：去 `docs/policies/`

## 推荐阅读顺序

1. `local-development.md`
2. `backend-change-playbook.md`
3. `openapi-workflow.md`
